====================================================================================================
F1 Score Interpretation Guide
====================================================================================================

F1 Score is the harmonic mean of precision and recall:
  - F1 = 2 × (Precision × Recall) / (Precision + Recall)
  - Ranges from 0% (worst) to 100% (perfect)

Performance Categories:
  ≥ 90%:  Excellent   - Outstanding performance
  80-89%: Good        - Strong performance with minor errors
  70-79%: Fair        - Moderate performance, noticeable errors
  60-69%: Poor        - Weak performance, significant errors
  < 60%:  Very Poor   - Unacceptable performance, major issues

Metrics Explained:
  • Precision: Of all predictions for this class, how many were correct?
               (Higher = fewer false positives)
  • Recall:    Of all actual instances of this class, how many were found?
               (Higher = fewer false negatives)
  • F1-Score:  Balanced measure of both precision and recall
  • Support:   Number of actual instances of this class in test set
